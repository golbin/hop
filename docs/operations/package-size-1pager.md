# 패키지 용량 절감

- 배경: 0.5.0 macOS ARM DMG는 82.8MB에서 105.4MB로 증가했다. WASM은 11.8→26.8MB, Quick Look 실행 파일은 각각 62.0→81.8MB가 됐다.
- 문제: HOP가 사용하지 않는 upstream PDF 가져오기 기본 기능이 WASM에 포함된다. Quick Look 최종 Swift 링크에는 명시적인 미사용 코드 제거·심볼 정리가 없다.
- 목표: HWP/HWPX 편집·저장·PDF 내보내기·미리보기·썸네일을 유지하면서 0.5.0과 0.4.5보다 작아질 수 있는 범위를 측정하고 구현한다.
- 비목표: upstream 수정, 기능 축소, 기존 공개 릴리스 교체. 공유 동적 라이브러리나 별도 서비스는 단순한 링크 설정으로 충분한지 확인하기 전에는 추가하지 않는다.
- 제약: upstream v0.9.0 고정, pnpm 사용, 세 OS 호환, 기존 서명·공증·배포 파일 이름 유지. 용량은 압축 전 실행 파일과 압축 후 배포 파일을 구분한다.
- 구현: WASM 기능을 명시하고 provenance에 기록한다. Quick Look 링크의 dead stripping과 서명 전 심볼 정리를 측정한다. 필요한 경우 안전한 release 최적화 설정을 비교한다. 측정 효과가 없거나 복잡도만 늘리는 변경은 제외한다.
- 검증: 동일 소스의 크기 비교, WASM API·Studio 호환성, HWP/HWPX 열기·편집·저장 및 PDF, Quick Look 실제 렌더링·썸네일 FFI, Rust 테스트·clippy, 번들 리소스·서명. Windows/Linux 빌드 설정의 정합성과 향후 배포 전 각 플랫폼 패키지 검증을 구분한다.
- 배포: 절감·회귀 검증 후 0.5.1 버전을 준비하고 main에 머지한다. 머지 후 필수 검사, 새 태그·draft 생성, 5개 플랫폼 빌드·서명·공증·업데이터 검증을 거쳐 공개한다.
- 복구: 공개 0.5.0과 태그를 유지한다. 변경은 별도 브랜치에 두며, 빌드 설정과 생성된 WASM/provenance를 함께 되돌린다. 실패한 0.5.1 draft는 공개하지 않는다.
